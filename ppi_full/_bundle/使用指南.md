## 2. 目标硬件说明（对应你给的 5 条配置）

| 你的配置 | 对这套实验意味着什么 | 建议 |
|---|---|---|
| **更大的台式机箱 + Wi-Fi** | 4090 48 GB 是**鼓风/改装卡**，长 30 cm+、功耗 450–600 W，需要 ≥360 mm 显卡位 + 底部进风；实验全程**离线**，Wi-Fi 只用于远程管理 | 机箱至少 3 个 120 mm 进风扇；"散热底座"建议用显卡支撑架，避免 PCB 下垂 |
| **i9-14 代或更新** | 决定 DataLoader 吞吐（`num_workers`）与 CPU 侧基线（RF 100 棵树） | 14900K/14900KF 或 Core Ultra 9 285K；`num_workers=4~8` |
| **128 GB DDR5** | **关键**：整个特征库 50 GB < 128 GB，第二 epoch 起全部命中 page cache，瓶颈从磁盘变成内存带宽 | 优先 **2×64 GB**（4×32 GB 在 14 代上普遍降到 4000–4800 MT/s） |
| **8 TB NVMe** | 包 50 GB + 每 run 约 35 MB 产物；一次全套约 200 个 run ≈ 7 GB | PCIe 4.0 即可（顺序读 7 GB/s 远快于需求）；留 ≥300 GB 余量 |
| **RTX 4090 48 GB（带散热底座）** | 模型本身只有 **4.16 M 参数**，48 GB 显存完全不是瓶颈，可用 `--bs 64~128`；瓶颈是 I/O 与 attention 的 1022 token 长度 | 驱动 ≥ 550、CUDA 12.4 轮子；`--bs 64 --lr 1e-4` 起步 |

补充：整机建议 **1200 W ATX 3.0 电源**（14900K 253 W + 4090 600 W 瞬时）。

## 8. 读结果前必须知道的口径

1. **数据缺口已掩码**：103 个蛋白无 AFDB 结构（pLDDT 写 100.0 哨兵，surf/iface 全零 + `has_surf/has_iface=0` 掩码），186 个无基因组窗口（`has_genome=0`）。受影响的 pair 占 2.38%（train 3.16% / val 1.33% / test 1.13%）。
2. **`L4-no-iface-bias` 在训练早期不可辨识**：`beta_init=0.0` 时 `bias = beta * iface_t` 近乎恒 0，4 步冒烟里与 R7 输出差仅 4e-7。要归因必须按真实规模训练（≥10 epoch）。
3. **`L4-no-global-path` 与 R5 同口径**：R5 本身就没有 text/genome 全局通路，两者指标应接近，属预期而非 bug。
4. **`L5-mixup` 是「开 mixup」正向消融**（`mixup_prob=0.25`），不是「关」。基座 R7 默认 mixup=0。
5. **`struct` 开关的实际通道是 `str`**：`run_all.py` 里 `_CH_ALIAS={"struct":"str"}`；R3–R7 此前被 P10 门禁误拦，已修。
6. **`num_workers`/`n_jobs`**：本机沙箱下曾被拒（命名管道），新机不受影响；若杀软拦截再退回 0/1。

## 9. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `CUDA out of memory` | `--bs` 太大 | 降到 32；48 GB 上 bs=64 正常应只占 ~8 GB |
| `PermissionError: [WinError 5]` 出现在 DataLoader | 杀软/沙箱禁止命名管道 | `config.py:82` 改 `num_workers: int = 0` |
| 训练极慢（>5 min/epoch） | 特征没进 page cache，或 `num_workers=2` 不足 | 先跑一遍 `python -c "import numpy as np; a=np.load('workdir/features/seq.npy',mmap_mode='r'); a[0,0].sum()"` 预热；`num_workers` 调 4–8 |
| `stats` 报 `FileNotFoundError ... predictions.npz` | 该 run 没跑完（只有 cfg.json） | 重跑该 tag/seed，或从 `--tags` 里去掉 |
| `run_all.py: RuntimeError: ... 特征 'struct' 缺失或全零` | 特征库没解包全 | 确认 `workdir/features/str.npy` 存在且 >20 GiB |
| `ValueError: Object arrays cannot be loaded...` | 别处用 `np.load` 读 predictions.npz | 加 `allow_pickle=True` |
| 中断后想续跑 | `run_all.py` 无断点续跑，会**覆盖**同 tag/seed | 先 `Copy-Item workdir\runs workdir\runs_bak -Recurse` |
